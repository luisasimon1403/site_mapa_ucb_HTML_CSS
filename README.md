# LOCatólica_HTML_CSS

Sistema web desenvolvido para auxiliar alunos, visitantes e colaboradores da Universidade Católica de Brasília (UCB) na localização de blocos acadêmicos, restaurantes e outros pontos de interesse do campus.

## Objetivo

O projeto foi criado com o objetivo de facilitar a navegação dentro da Universidade Católica de Brasília, reunindo informações sobre os blocos do campus e os estabelecimentos disponíveis em uma única plataforma de fácil acesso.

## Funcionalidades

* Visualização dos blocos da universidade.
* Consulta de informações sobre cada bloco.
* Consulta dos restaurantes presentes no campus.
* Página de perguntas frequentes (FAQ).
* Navegação simples e intuitiva entre as páginas.

## Tecnologias Utilizadas

* HTML5
* CSS3

## Como Executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo:

```text
index.html
```

A página principal do sistema é o arquivo **index.html**.
